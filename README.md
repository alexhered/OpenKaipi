# OpenKaipi

Hi, I'm Alex. OpenKaipi is my tool for building projects with AI in a safer way.

I made it because at university, and while learning to build things with AI, I kept leaving stuff like API keys or old libraries in my code without noticing. So now you can upload your project on [openkaipi.com](https://openkaipi.com), it checks it with a few filters, and tells you what looks wrong in simple words.

The filters are made by the community. If you have an idea for a new one, you can add it through a pull request here on GitHub.

I'm leaving the project open in case someone wants to use it for their own projects too. It's very early and I'm learning as I go, so please be patient with me. You can see what I'm working on in the [Issues](https://github.com/alexhered/OpenKaipi/issues).

OpenKaipi doesn't keep your code. If it finds a secret, it hides it in the report. And it will never tell you a project is "100% secure", because nobody can really promise that. It only helps you catch common mistakes.
